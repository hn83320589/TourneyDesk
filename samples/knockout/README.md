# 單淘汰 11 人：籤表與連鎖清除（手算）

## 1. 種子與籤表大小

種子依（積分高→低、註冊編號小→大）：本例積分隨註冊編號遞減，所以**種子 k = 註冊編號 #k**。
N = 11 → 籤表大小 S = 16（≥ 11 的最小 2 的冪次），需要 S − N = **5 個輪空**。

## 2. 標準位置

positions(2) = [1, 2]；positions(2k) 把 positions(k) 的每個 s 展開為 s、2k+1−s：

- positions(4) = [1, 4, 2, 3]
- positions(8) = [1, 8, 4, 5, 2, 7, 3, 6]
- positions(16) = [1, 16, 8, 9, 4, 13, 5, 12, 2, 15, 7, 10, 3, 14, 6, 11]

每兩個一組即第 1 輪：1v16、8v9、4v13、5v12、2v15、7v10、3v14、6v11。
種子 12～16 不存在（空位），所以它們的對手 **1、4、5、2、3** 第 1 輪輪空——正好是最高的 5 位種子，且輪空只在第 1 輪。

逐格結果見 [expected-bracket-11.txt](expected-bracket-11.txt)（第 9 場起為「某場勝者」，第 16 場為季軍戰：兩場準決賽的敗者）。
