# 瑞士制第 1 輪配對：手算

第 1 輪所有人累計分數都是 0、沒有任何歷史，因此：

- ① 重複對戰 = 0、② 曾輪空 = 0、④ 分差平方和 = 0，對所有方案都相同；
- ③ 輪空者的賽前排名越大越好 → **最後一名輪空**；
- ⑤ 讓排名最小的未配對者，對手排名越大越好 → 依序得到 (1, n′)、(2, n′−1)、…（n′ 為扣掉輪空後的人數）。

先後手：大家的先手次數都是 0，也都沒有上一場 → 依「賽前排名較高者先手」。
桌號依每場 hi（較高排名）由小到大排列。
