# 瑞士制 12 人 5 輪：逐步手算

選手 A～L（註冊編號 1～12，積分 2000、1950、…、1450 遞減）；M（#13，積分 1700）自第 3 輪起**遲到加入**。
K 自第 4 輪起**退賽**；L 自第 5 輪起**退賽**。第 2 輪 K **棄權**；第 3 輪與第 5 輪人數為奇數 → **輪空**。輪空得 2 半分。
分數一律以**半分**表示。

符號：`(hi, lo)` 為兩人的賽前排名（hi < lo）。字典序目標：
① 重複對戰數 → ② 輪空者曾輪空 → ③ 輪空者排名越後面越好 → ④ 分差平方和 → ⑤ 依 hi 排序後，hi 小者先比、lo 越大越好。
⑤ 等價於：**目前排名最小的未配對者，其對手排名越大越好**（在不破壞 ①～④ 最佳值的前提下），反覆進行。

先後手：先手次數少者先手 → 相同時上一場後手者先手 → 仍相同時排名高者先手。桌號依 hi 排列。

## 第 2 輪（12 人）

排名：1 A、2 B、3 D、4 F、5 H（2 分）｜6 C、7 J（1 分）｜8 E、9 G、10 I、11 K、12 L（0 分）。

- ① = 0 可達成。
- ④：分數群組大小 5、2、5 都是奇數。C–J 已交手，不能在 1 分組內互配，所以 2 分組要有一人「降」到 1 分組（分差 1，平方 1），1 分組剩下的一人再降到 0 分組（平方 1），其餘組內配對 → **④ = 2**（最小）。
- ⑤：
  - A（1）的對手越後面越好：A 降到 1 分組配 **J（7）** 仍可維持 ④ = 2，配 0 分組會使 ④ ≥ 4 → (1,7)。
  - B（2）：2 分組剩 B、D、F、H 必須組內配對，B 配 **H（5）**（未交手）→ (2,5)，剩 D–F → (3,4)。
  - C（6）：降到 0 分組，對手越後面越好 → **L（12）** → (6,12)。
  - E（8）：剩 E、G、I、K，E 配 **K（11）** → (8,11)，剩 G–I → (9,10)。
- 先後手：J、H、L、K 先手次數 0 < 對手的 1 → 先手；D–F 都是 1 次、上一場都先手 → 排名高的 D 先手；G–I 都是 0 次、上一場都後手 → G 先手。

| 桌 | 先手 | 後手 | 結果 |
|---|---|---|---|
| 1 | J | A | 0-1（A 勝） |
| 2 | H | B | 和 |
| 3 | D | F | 1-0 |
| 4 | L | C | 0-1（C 勝） |
| 5 | K | E | **先手棄權**（E 得 2，不算輪空） |
| 6 | G | I | 0-1（I 勝） |

賽後：A、D = 4；B、C、H = 3；E、F、I = 2；J = 1；G、K、L = 0。

## 第 3 輪（13 人，M 加入）

M 加入時為 0 分，與 G 同為積分 1700，依註冊編號 G（#7）排在 M（#13）前。
排名：1 A、2 D（4）｜3 B、4 C、5 H（3）｜6 E、7 F、8 I（2）｜9 J（1）｜10 G、11 M、12 K、13 L（0）。

- 人數 13 → 需要一位輪空。沒有人輪空過 → ② = 0；③ 輪空者排名越大越好 → **L（13）**（其餘 12 人存在無重複的方案）。
- ④：剩下的群組大小為 2、3、3、1、3。奇數群組有 3、2、1、0 分組 → 至少需要兩組跨組配對：3↔2（平方 1）與 1↔0（平方 1）→ **④ = 2**。
- ⑤：
  - A（1）只能配 D（2）（A 往下配會讓 ④ 變大）→ (1,2)。
  - B（3）：可以降到 2 分組；B–H 已交手，所以 3 分組必須是 C–H 互配、B 往下 → B 的對手越後面越好 → **I（8）**（未交手）→ (3,8)。
  - C（4）配 H（5）→ (4,5)；E（6）配 F（7）→ (6,7)。
  - J（9）降到 0 分組，對手越後面越好 → **K（12）** → (9,12)；剩 G–M → (10,11)。
- 先後手：A 先手 1 次 < D 的 2 次 → A 先手；I 先手 0 次 → I 先手；C–H 都 1 次，C 上一場後手 → C 先手；E–F 都 1 次、上一場都後手 → E（排名高）先手；J–K 都 1 次、上一場都先手 → J 先手；M 沒有對局過、0 次 → M 先手。

| 桌 | 先手 | 後手 | 結果 |
|---|---|---|---|
| 1 | A | D | 和 |
| 2 | I | B | 0-1（B 勝） |
| 3 | C | H | 1-0 |
| 4 | E | F | 0-1（F 勝） |
| 5 | J | K | 1-0 |
| 6 | M | G | 1-0 |
| 輪空 | L | | +2 |

賽後：A、B、C、D = 5；F = 4；H、J = 3；E、I、L、M = 2；G、K = 0。

## 第 4 輪（12 人，K 退賽）

排名：1 A、2 B、3 C、4 D（5）｜5 F（4）｜6 H、7 J（3）｜8 E、9 M、10 I、11 L（2）｜12 G（0）。

- ④：奇數群組為 4 分組（F）與 0 分組（G）。G 往上最便宜是配 2 分組（分差 2，平方 4）；之後 2 分組變成奇數，要有一人配 3 分組（1），3 分組再有一人配 F（1）→ **④ = 6**。
- 5 分組內：A–D 已交手 → 只能是 {A–B, C–D} 或 {A–C, B–D}。
- ⑤：
  - A（1）的對手越後面越好 → **C（3）** → (1,3)，B–D → (2,4)。
  - F（5）配 3 分組，越後面越好 → **J（7）** → (5,7)。
  - H（6）配 2 分組，越後面越好 → **L（11）**。可行性檢查：G 已和 F、I、M 交手，只能配 E；剩 M–I 未交手 ✓ → (6,11)。
  - E（8）只能配 G（12）→ (8,12)；M–I → (9,10)。
- 先後手：A–C 都 2 次、上一場都先手 → A 先手；B（1 次）< D（2 次）→ B；F（1）< J（2）→ F；H–L 都 1 次，H 上一場後手 → H；G（1）< E（2）→ G；M–I 都 1 次、上一場都先手 → M（排名高）。

|---|---|---|---|
| 1 | A | C | 0-1（C 勝） |
| 2 | B | D | 1-0 |
| 3 | F | J | 和 |
| 4 | H | L | 0-1（L 勝） |
| 5 | G | E | 1-0 |
| 6 | M | I | 1-0 |

賽後：B、C = 7；A、D、F = 5；J、L、M = 4；H = 3；E、G、I = 2；K = 0（已退賽，凍結）。

## 第 5 輪（11 人，L 退賽）

排名：1 B、2 C（7）｜3 A、4 D、5 F（5）｜6 M、7 J（4，M 積分較高）｜8 H（3）｜9 E、10 G、11 I（2）。

- 人數 11 → 輪空。無人輪空過（L 已退賽）→ 輪空給排名最後的 **I（11）**。
- 剩下 10 人中的限制：A–D、D–F 已交手 → 5 分組只能 A–F 互配，D 必須降到 4 分組；**E–G 已交手** → 2 分組不能互配。
  - G 的可配對象中，最便宜的是 H（分差 1）；E 不能配 H（已交手），最便宜是 4 分組（平方 4）。
  - 最佳結構：B–C（0）、A–F（0）、G–H（1）、E 配 M 或 J（4）、D 配另一人（1）→ **④ = 6**。
- ⑤：(1,2) B–C、(3,5) A–F 相同；接著 hi = 4 的 D：對手越後面越好 → **J（7）**（而非 M（6））→ (4,7)，於是 E–M → (6,9)、H–G → (8,10)。
- 先後手：B–C 都 2 次，C 上一場後手 → C；F（2）< A（3）→ F；D–J 都 2 次、上一場都後手 → D；E–M 都 2 次，E 上一場後手 → E；H–G 都 2 次、上一場都先手 → H。
