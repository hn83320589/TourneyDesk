# 循環賽排程：手算

## 演算法

1. **種子**：依（積分高→低、註冊編號小→大）編為 S1..Sn。
2. **輪次（圓桌法）**：m = n（偶數）或 n+1（奇數，Sm 為虛擬種子，配到即輪空）。
   第 r 輪（r = 1..m−1）：Sr 對 Sm；其餘 Si、Sj 若 i + j ≡ 2r (mod m−1) 則對戰（餘數用 1..m−1 表示）。
   因 m−1 為奇數，每對種子恰好在一輪相遇；奇數人數時每人恰好輪空一次。
3. **先後手**：對 i < j，i + j 為奇數 → Si 先手，否則 Sj 先手。每人先後手差 ≤ 1（偶數場時相等）。
4. **桌號**：每輪依較小種子由小到大排列。
5. **雙循環**：第二循環複製第一循環並互換先後手。

## 單循環 7 人（single-7.json）

種子：S1=#2 陳二(1900)、S2=#5 王五(1820)、S3=#3 張三(1750)、S4=#1 林一(1600)、S5=#4 李四(1500)、S6=#6 趙六(1400)、S7=#7 孫七(1300)。
m = 8（S8 為虛擬），m−1 = 7。

| 輪 | 2r mod 7 | 對戰（種子，先手在前） | 輪空 |
|---|---|---|---|
| 1 | 2 | S2–S7（9 奇→S2 先）、S3–S6（9 奇→S3）、S4–S5（9 奇→S4） | S1 |
| 2 | 4 | S1–S3（4 偶→S3 先）、S4–S7（11 奇→S4）、S5–S6（11 奇→S5） | S2 |
| 3 | 6 | S1–S5（偶→S5）、S2–S4（偶→S4）、S6–S7（奇→S6） | S3 |
| 4 | 1 | S1–S7（偶→S7）、S2–S6（偶→S6）、S3–S5（偶→S5） | S4 |
| 5 | 3 | S1–S2（奇→S1）、S3–S7（偶→S7）、S4–S6（偶→S6） | S5 |
| 6 | 5 | S1–S4（奇→S1）、S2–S3（奇→S2）、S5–S7（偶→S7） | S6 |
| 7 | 0→7 | S1–S6（奇→S1）、S2–S5（奇→S2）、S3–S4（奇→S3） | S7 |

例：第 1 輪 i=3 → j ≡ 2−3 ≡ 6，所以 S3–S6。
檢查：每位選手 6 場，先手恰好 3 場（S1：第 5、6、7 輪；S4：第 1、2、3 輪…），每人輪空 1 次。

換成註冊編號即 [expected-single-7.txt](expected-single-7.txt)，例如第 2 輪第 1 桌 S3–S1 = #3 先手對 #2。

## 雙循環 4 人（double-4.json）

種子：S1=#4 李四(1800)、S2=#2 陳二(1700)、S3=#3 張三(1600)、S4=#1 林一(1500)。m = 4，m−1 = 3。

| 輪 | 對戰（種子） | 先手判定 | 註冊編號（先手–後手） |
|---|---|---|---|
| 1 | S1–S4、S2–S3 | 5 奇→S1；5 奇→S2 | #4–#1、#2–#3 |
| 2 | S1–S3、S2–S4 | 4 偶→S3；6 偶→S4 | #3–#4、#1–#2 |
| 3 | S1–S2、S3–S4 | 3 奇→S1；7 奇→S3 | #4–#2、#3–#1 |
| 4–6 | 第二循環：第 1～3 輪先後手互換 | | #1–#4、#3–#2／#4–#3、#2–#1／#2–#4、#1–#3 |

每人第一循環先手 1 或 2 次（差 ≤ 1），雙循環合計恰好 3 先 3 後。
